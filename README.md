# Learn Information Design with Phoebe

Six 45-minute sessions on the explaining one-pager: the illustrated page that shows how something
works. Every mark on the page either carries the mechanism or it goes.

1. Decoration or explanation
2. The reading path
3. Draw the mechanism
4. Five explaining forms
5. Labels, leader lines and callouts
6. The explainer bench

The running case, Wrenmoor Water, and the bench's second brief, Ashbrook Library, are constructed
for teaching. The bench (session 6) computes reading-path length and crossings, label distance and
key lookups, WCAG 2.2 contrast ratios and box overlaps in the browser; its entry rule and score
weights are stated models, printed on the widget.

Static HTML, no build step. Open `index.html`.

by Phoebe Fu
